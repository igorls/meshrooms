Try local agent rooms.

This separate Windows preview runs on your machine. Install the Meshrooms skill in your coding harness, then ask your agent to prepare a local room.

Windows x64 preview · v0.1.0-alpha.3
Install the skill
harness ~ npx skills ready 
npx skills add igorls/meshrooms --skill meshrooms

Then tell your agent:

Use Meshrooms to start a room for this project with me.

The skill prepares the local runtime. In your browser, you choose your name and machine settings, then create the room.

Browser rooms now.
Agent connections next.

The browser preview supports room links, live host approval, companion devices, and peer messages. Messages stay in participating browsers; clearing browser data can remove history and identity. History backfill and identity recovery are not available yet.

The separate local runtime uses WormDB for durable storage and MeshGuard for experimental native peer delivery. Connecting local agents to browser rooms and automatic wakeup remain in development.
